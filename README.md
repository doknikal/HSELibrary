# HSE Library

Нативное приложение в строке меню (menubar) для macOS: доступ к электронным
ресурсам библиотеки ВШЭ через прокси. Без скриптов — весь код на Swift.

## Как работает

macOS 27 игнорирует системный PAC (проверено: ни http://, ни file:// PAC не
применяются Safari/CFNetwork). Поэтому приложение работает по логике white-list
само:

- встроенный локальный прокси **127.0.0.1:18080** (только loopback, наружу
  не торчит), прописывается как manual HTTP/HTTPS proxy;
- домены из официального списка `https://libtest.hse.ru/www.txt` идут через
  `libtest.hse.ru:3128` с авторизацией из Связки ключей;
- всё остальное — напрямую;

## Безопасность

- логин и пароль хранятся только в Связке ключей (security API, класс
  kSecClassInternetPassword); они никогда не попадают в argv, env или файлы;
- авторизация подставляется в момент соединения с прокси ВШЭ, браузер ничего
  не спрашивает;
- локальный прокси принимает соединения только с 127.0.0.1 и сразу рвёт
  чужие;
- список доменов загружается по HTTPS;
- никаких сторонних зависимостей: только системные framework'и
  (Network, Security, Foundation).

## Установка

1. Скачайте `HSE_Library_1.2.0.dmg` со страницы **[Releases](../../releases)**.
2. Откройте `.dmg` и перетащите **HSE Library** в папку «Программы».

При первом запуске macOS может попросить подтверждение (приложение без
подписки разработчика): правой кнопкой → «Открыть».

## Использование

1. В строке меню появится значок ВШЭ.
2. **Войти (логин ВШЭ)…** — логин/пароль библиотеки ВШЭ (не ЛМС).
3. **Включить прокси** — ресурсы ВШЭ открываются как из кампуса.
4. **Проверить доступ** — тестовая проверка.
5. **Обновить список ресурсов** — перезагрузить www.txt.
6. Выход из приложения выключает прокси автоматически.

## Сборка

```bash
swiftc -swift-version 5 -O -o build/HSELibrary Sources/main.swift
# затем упакуйте бандл: MacOS/HSELibrary, Resources/AppIcon.icns, Info.plist
codesign --force -s - "HSE Library.app"
```

Структура: `Sources/main.swift` — всё приложение (UI, ключи, прокси-релея).
